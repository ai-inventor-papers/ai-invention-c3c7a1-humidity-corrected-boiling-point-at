# Boiling Point Model Comparison Experiment

This experiment compares four boiling point models against synthetic field measurements across altitudes from 0 to 5000m:

1. **ISA Baseline** - Uses ISA standard atmosphere pressure at altitude
2. **ISA (Measured Pressure)** - Uses Clausius-Clapeyron physics with locally measured pressure (fair comparison baseline)
3. **Kinetic Model** - Adds superheat correction for nucleation effects
4. **Dissolved Gas Model** - Accounts for boiling point depression from dissolved gases

## Key Results

| Model | RMSE (°C) | MBE (°C) | MAE (°C) |
|-------|-----------|----------|----------|
| ISA Baseline (ISA Pressure) | 0.651 | -0.523 | 0.538 |
| ISA (Measured Pressure) | 0.659 | -0.532 | 0.550 |
| **Kinetic Model** | **0.390** | **-0.012** | **0.339** |
| Dissolved Gas Model | 0.776 | -0.668 | 0.675 |

**Finding**: The Kinetic Model (accounting for superheat from nucleation) significantly outperforms all baselines with RMSE=0.39°C and near-zero bias (MBE=-0.012°C). The Dissolved Gas Model performs worse than the ISA baseline because the gas depression effect is smaller than the kinetic superheat effect in typical boiling conditions.

## Physical Model Details

### ISA Baseline
Uses the barometric formula: P = P₀ × exp(-gMh/RT₀)
Then applies Clausius-Clapeyron: ln(P/P₀) = -Lᵥ/Rᵥ × (1/T - 1/T₀)

### Kinetic Model
Adds superheat: ΔT = k₁ × q⁰·³³ × (P₀/P)⁰·⁵ + 0.5°C
Where q = heat flux (default 5000 W/m²), k₁ = 0.001 empirical constant

### Dissolved Gas Model
Subtracts depression: ΔT = 0.1 × (P₀/P) °C
Based on Henry's law for air-saturated water (~8-10 mg/L O₂)
